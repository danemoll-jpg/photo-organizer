## RESOLVED — Real-usage findings from user's own testing — GPS logging + panel UX

Spawning a console app from a process with no console of its own (`pythonw.exe`, how the dashboard launches) makes Windows create a brand-new console window for the child — and the Remote Access panel's status check calls this **every 5 seconds for the dashboard's entire lifetime** (`self._port_status_tick`, scheduled unconditionally in `__init__`, independent of whether that panel is expanded or whether GPS/Captioning/anything else is running).
